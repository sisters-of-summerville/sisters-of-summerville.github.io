# Sisters of Summerville Arcade update

Upload the contents of this folder to the root of the
`sisters-of-summerville.github.io` repository, preserving the `games` folder.
Replace the existing files when GitHub asks.

This update:

- adds an **Arcade** link to the main site navigation;
- gives the games page the Sisters of Summerville site styling;
- expands a game to the full browser viewport after **Start Game**;
- restores the normal page when **Arcade**, **Choose Another Game**, or Escape is used;
- updates the offline cache to version 5 so the clean `/games` URL receives the new files.

After GitHub Pages finishes publishing, open:

https://sisters-of-summerville.github.io/games

If an already-open tab still shows an older version, refresh it once.
